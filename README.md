## Customize before publishing
1. Replace every `https://www.fiverr.com/` with your exact Fiverr profile URL.
2. Add your real project GitHub repository URLs where appropriate.
3. If you want, add a professional profile photo to the hero section.
4. Deploy the folder to GitHub Pages, Netlify, Vercel, or another static host.
